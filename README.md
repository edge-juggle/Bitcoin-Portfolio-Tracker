## 📊 Overview

**Bitcoin Portfolio Tracker** is a desktop application designed for Bitcoin investors who want a convenient way to monitor their portfolio without relying entirely on browser-based services.

Whether you're a long-term HODLer or an active investor, the software helps you organize your holdings, monitor portfolio performance, and gain valuable insights into your Bitcoin investments.

# 📦 Installation

The application is included inside this repository.

### Windows

1. Download or Clone this repository.

2. Locate:

```
Bitcoin Portfolio Tracker
```

3. Double-click the executable.

4. Complete the installation.

5. Launch the application.

---

### macOS

1. Download this repository.

2. Open the folder.

3. Locate:

```
Bitcoin Portfolio Tracker
```

4. Move it into the **Applications** folder (if applicable).

5. Open the application.

---

### Linux

Make the application executable:

```bash
chmod +x "Bitcoin Portfolio Tracker"
```

Run:

```bash
./"Bitcoin Portfolio Tracker"
```
